# insert_tool — 文本训练日志导入工具

## 目的

将用户在手机笔记 APP 中记录的纯文本训练日志，自动解析为 GYM 网页的结构化数据（TrainingDay → DayExercise → SetRecord），通过训练动作库的动作别名匹配将简写映射到标准动作名。

---

## 训练分化模式

```
上肢 → 下肢 → 休息 → 上肢 → 下肢 → 上肢 → 休息
（7 天循环）
```

## 解析规则要点

1. **动作识别**：首先查映射表，未命中则原样保留作为动作名
2. **裸重量**：单独出现的 `XXkg` 需根据上下文（上肢日/下肢前侧日/下肢后侧日）推断对应动作
3. **碎碎念过滤**：如"好累啊"、"下次可以加重了"、"嘎吱"等人声内容需识别并忽略
4. **组数次数组数**：用户笔记格式可能不完整（缺组数、缺次数），解析时需容错处理
5. **日期推断**：文本中若无显式日期，需通过训练分化模式（7 天循环）反推日期，或让用户在导入时指定起始日期
6. **下肢日类型区分**：通过关键词判断——"前侧focus"→深蹲，"后侧focus"/"后侧日"→硬拉

---

## 目标输出

解析后生成标准 `ExportData` 格式，包含：
- `exercises`：训练动作数组（自动创建缺失的动作，默认分类）
- `trainingDays`：训练日卡片数组，每条包含 date、exercises（DayExercise[]）
